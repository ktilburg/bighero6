# Big Hero 6 Deliverables
In deze zip hebben we al onze deliverables geplaatst.

- In de map "Get2Know" staat de code van ons eindproduct. Het app.py bestand kan gerund worden als python bestand om het product lokaal te runnen (via localhost op de url: http://127.0.0.1:5026/). En met de command "ngrok http 5026" start het op via ngrok, wat we gebruikt hebben voor onze server (dit is optioneel).
- In de mappen gelabeld als sprint x staan de deliverables uit die sprint vanuit figma en dergelijke, waarbij x het nummer van de sprint is.
- Het document "onderzoeksdocumentatie" bevat alle documentatie over ons onderzoek, opgedeeld in sprints. Hierbij verwijzen we naar de deliverables uit die mappen gelabeld als sprint x.
- In de map "onepager" staat alle code van onze onepager. Deze kan via de index.html gerund worden om de onepager lokaal te bekijken.

De onepager staat online op de volgende url:
https://project.cmi.hr.nl/2025_2026/idp_ds_t6/
